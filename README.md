# What The Fusilli

A small site that decides what pasta shape you're having today, and explains how each
shape is actually manufactured — the die that produces it, why it's extruded or rolled
or formed by hand.

Live at **[whatthefusilli.com](https://whatthefusilli.com)**.

## What's here

| URL | What it does |
|---|---|
| `/` | Picks a shape on load. Reroll button, plus mood filters that narrow the pool. |
| `/browse` | All 49 shapes grouped into six families, with search and family filters. |
| `/shapes/bucatini` | One shape: pronunciation, region, sauce pairings, how it's made, its die. |

No framework. The HTML is generated by `build.js` — page shells only; all content
comes from `js/data.js` in the browser.

```bash
node build.js
```

That writes `index.html`, `browse/index.html`, a directory per shape under `shapes/`,
a `404.html`, and the single-file bundle. GitHub Pages serves the directories, which is
what gives the URLs no `.html` extension. The old `browse.html` and `shape.html?id=…`
URLs remain as redirect stubs.

## Editing

Everything about the pasta lives in [`js/data.js`](js/data.js), one object per shape:

```js
{
  id: 'bucatini',
  name: 'Bucatini',
  cat: 'long',          // long | ribbon | tube | shape | small | filled
  method: 'extruded',   // extruded | rolled | hand | stamped
  icon: 'strand-hollow',// key in js/icons.js
  sauces: ['chunky', 'meaty', 'cheesy'],
  made: '…', die: '…', fact: '…'
}
```

Add an entry, run `node build.js` to mint its page, and it appears everywhere. The `icon`
must match a key in [`js/icons.js`](js/icons.js), which holds a hand-built SVG for each
shape and recolors itself for light and dark mode. Editing an existing pasta needs no
rebuild — only adding or removing one does, since that changes which pages exist.

## The single-file build

`build.js` also writes `dist/index.html`: the whole site inlined into one self-contained
page, with links rewritten to hash routes. Useful for sharing the site as a single file.
